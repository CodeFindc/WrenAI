# Runtime dependencies for the Dual-Track example servers.

# intentionally NOT a frozen environment snapshot.
#
# The heavy lifting (WrenEngine, MDL, memory, connectors) comes from the
# parent package, installed editable BEFORE this file:
#
#     pip install -e core/wren[<datasource>,memory]     # engine + connectors
#     pip install -e sdk/wren-langchain                 # WrenToolkit + langchain/langgraph
#     pip install -r sdk/wren-langchain/examples/requirements.txt
#
# `wren-langchain` already declares langchain / langgraph / langchain-core /
# pydantic / wren-engine as dependencies, so they are NOT re-pinned here.
# Pick the datasource extra(s) you need at the core/wren step (mysql,
# postgres, bigquery, ...) — that's where DB drivers belong.
